# Atharva Chaudhari — Portfolio

Professional portfolio for Atharva Chaudhari, an AI/ML Engineer at the University of Illinois Urbana-Champaign.

This repository contains the complete portfolio website, including detailed experience, eight chronological project case studies, education, publications, achievements, credentials, custom project artwork, downloadable résumé, and responsive interactions.

## Deploy with Vercel

Import this repository into Vercel. The included `vercel.json` publishes the static website from `dist` without a build step.
