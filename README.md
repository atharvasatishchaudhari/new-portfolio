# Atharva Chaudhari — Portfolio

Professional portfolio for Atharva Chaudhari, an AI/ML Engineer at the University of Illinois Urbana-Champaign.

The website contains:

- A detailed professional introduction and technical focus
- Research and engineering experience
- Eight project case studies arranged chronologically
- Architecture flows, measurable results, technology stacks, and source links for every project
- Education, publications, awards, teaching recognition, and professional credentials
- A downloadable résumé and direct contact links
- Responsive layouts for desktop, tablet, and mobile

## Deploy on Vercel

Import this repository into Vercel. The included `vercel.json` publishes the complete static site from the `dist` directory without a build step.

## Local preview

Open `dist/index.html` in a browser, or serve the directory with any static web server.

All website content, styles, interactions, images, and the résumé are contained inside `dist`.
